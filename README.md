# Java Project Campus Navigation GUI

A Java AWT desktop application for browsing campus buildings, departments,
hostels, laboratories, and bus stops.

## Requirements

- Java Development Kit (JDK) 8 or later

## Run the application

From the project directory, compile and start the application:

```bash
javac CampusNavigation.java
java CampusNavigation
```

## Demo login

- Username: `admin`
- Password: `123`

After logging in, use the category buttons to view campus information or search
for `Library`, `Hostel`, or `CSE`.

## Features

- AWT-based login screen
- Campus information for buildings, departments, hostels, labs, and bus stops
- Search for selected campus locations
- Status messages for application activity
