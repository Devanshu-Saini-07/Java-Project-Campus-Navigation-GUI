🔄Implementation Timeline

Analysis & Diagnosis

Identified root causes: flickering from AWT Canvas.update(), overlapping nodes from lack of coordinate scaling, emoji rendering artifacts, and incorrect hit detection.

Coordinate Transformation System

Designed getScreenPos() method with aspect-ratio preservation. Calculates bounding box, scale factor, and offset to fit all locations within padded canvas.

Double Buffering Implementation

Override update() to call paint() directly. Create offscreen Image buffer matching canvas dimensions. Graphics2D antialiasing hints enabled.

Vector Icon System

Replaced emoji glyphs with geometric shapes drawn programmatically. Different icons for building, hostel, lab, department, bus stop, facility, and entry gate categories.
